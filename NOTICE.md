# Attribution and third-party notices

## Original hardware inspiration — MacDat

**Creator:** MacDat  
**Original project:** [TPU Feed Assist Module Remote Controller](https://makerworld.com/en/models/2704030)  
**Platform:** MakerWorld (Bambu Lab)  
**Original project's purpose:** external, repositionable physical remote control for the Bambu Lab TPU Feed Assist Module.

MacDat created and published the original remote hardware design. The project's external three-button controller and SH1.0 button wiring/extension method are the **hardware inspiration and starting point** for this ESP32-S3 bridge concept. Credit for the original design belongs to **MacDat**.

**Please visit, download, and support the original project directly on MakerWorld.** We appreciate the work that made this extension concept possible.

### What this repository adds

The firmware, Wi-Fi/MQTT/HTTP control interface, isolated electronic button actuation proposal, and proposed inline hardware sensing design are **new, experimental additions** by this project's contributors. They are *not* provided by MacDat and should not be attributed to MacDat.
